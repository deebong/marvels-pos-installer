How to set up the Google Sheet (2 minutes, no coding)
  1. Create a new Google Sheet.
  2. Open Extensions > Apps Script, delete the sample code and paste the backend script.
  3. Deploy > New deployment > Web app — Execute as: Me, Who has access: Anyone — then Deploy and authorise.
  4. Copy the Web app URL (ends in /exec), paste it below and connect.

Tabs Products, Sales, SaleItems, StockMovements, Settings, SyncLog are created automatically. Already using an older script? Paste the new Code.gs and redeploy as a New version to enable offline sync.

In Apps Script: Choose getAuthSetupCode() from the dropdown above the code editor, then click the Run button.
